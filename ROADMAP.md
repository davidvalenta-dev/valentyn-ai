# Research roadmap

1. Repeat frozen-policy comparisons across independent training seeds and matched inference budgets. Require meaningful gains over random and strong symbolic search.
2. Improve the curriculum and compositional state representations using training/validation data; create a new locked test suite before evaluating changes.
3. Introduce arithmetic and reusable lemmas with separate Lean-checked datasets and stronger retrieval baselines. Do not extrapolate propositional results to mathematical research.
4. Scale only after evidence supports additional memory and compute. Test on an actual 8 GB machine before promising an 8 GB deployment envelope.
5. Study research-mathematics subproblems with expert-reviewed formal statements. A breakthrough requires both verified correctness and independent novelty assessment.
